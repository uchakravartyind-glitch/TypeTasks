# Task Orbit

A responsive, framework-free task tracker built with HTML, CSS, and strict TypeScript.

## Run locally

1. Compile the TypeScript with `tsc`.
2. Serve this folder with any static server.
3. Open `index.html` through that server.

The generated `app.js` and `model.js` files are intentionally kept beside their TypeScript sources so a static host can serve the app directly.
